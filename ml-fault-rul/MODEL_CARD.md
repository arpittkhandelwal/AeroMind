# Model Card — UAV Engine Fault Classifier & RUL Estimator

## Model Details
- **Architecture**: Multi-stage pipeline.
  - **Stage 1 (Anomaly Detection)**: Isolation Forest trained on physics model residuals (`ThermodynamicModel` delta vs expected).
  - **Stage 2 (Fault Classification)**: Random Forest Classifier (multi-class) over 8 classes.
  - **Stage 3 (RUL Estimation)**: Gradient Boosted Regressor predicting Remaining Useful Life (RUL) in hours.
- **Version**: 1.0 (MVP)
- **Framework**: Scikit-Learn (v1.3+)
- **Domain**: DRDO Problem Statement 26054 (MALE UAV Piston Engine Digital Twin)

## Intended Use
- **Primary Use Case**: Real-time continuous inference on edge/telemetry stream for MALE UAVs.
- **Out of Scope**: Real-world fleet deployment (requires calibration on real engine failure datasets; current models are trained on synthetic but physics-informed data).

## Training Data
- **Source**: Synthetic telemetry generated by `data-sim` module.
- **Dataset Size**: 200+ full missions (~800,000+ telemetry frames).
- **Class Balance**: Artificially balanced. Classes include `nominal`, `misfire`, `injector_fault`, `sensor_drift`, `overheating`, `combustion_instability`, `lubrication_issue`, `abnormal_vibration`.
- **Validation Split**: 80/20 train/test split *by mission* (to prevent frame leakage).

## Evaluation Results
*See `metrics.json` for live training metrics.*
- **Fault Classifier (Random Forest)**:
  - Consistently achieves >0.90 F1-score on the held-out test missions across all classes.
  - Most challenging boundary: distinguishing minor `sensor_drift` from nominal engine variance in high-noise environments.
- **RUL Estimator**:
  - MAE (Mean Absolute Error) is typically <5 hours on the 200h scale.
  - Effectively correlates RUL drop with accumulated fault severity (weighted by anomaly score).

## Known Limitations
1. **Synthetic Bias**: The model flawlessly learns the generator's physical assumptions. Real-world sensor degradation, CAN bus noise, and unmodeled mechanical resonances are not fully captured.
2. **Single Fault Assumption**: The classifier is currently trained on single-mode failures. Composite faults (e.g., misfire *leading to* abnormal vibration) are not explicitly labeled.
3. **Thermal Inertia Approximation**: Oil temperature lag is modeled as a simple first-order system (τ=60s). Real thermal dynamics involve multiple varying time constants.

## Feature Importance (Explainability)
The model leverages SHAP-inspired explainability mapped to physics residuals. The top driving features for each class intuitively map to physical phenomena:
- **Overheating**: `residual_cht_c`, `residual_egt_c`
- **Lubrication Issue**: `residual_oil_pressure_kpa`, `residual_oil_temp_c`
- **Combustion Instability**: `egt_c_rolling_std`, `rpm_rolling_std`
- **Abnormal Vibration**: `vibration_g`, FFT-extracted harmonics
